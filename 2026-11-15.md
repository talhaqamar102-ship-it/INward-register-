  - Removed `#btn-admin-lock` click wiring, deleted unused `.sub-header-right .btn-primary` and `data-short-label` CSS rules, and added `.admin-tab-heading` / `.admin-tab-icon` alignment rules.

### Phase 1 — Print Guard, WCAG Contrast, Typography Floor & Layout Polish
- **[src/utils/requisitionLogic.test.ts](src/utils/requisitionLogic.test.ts)**:
  - Added the `Monochrome Print Guard` test (`extractBlocks`) parsing `@media print` and `.printable-slip-box` blocks in `src/style.css` to reject `--su-*` variables and any non-black/white hex colors.
  - Added dynamic WCAG 2.1 contrast assertions (`>= 4.5:1`) resolving CSS custom properties for semantic badges and muted text across `--su-bg-*` surfaces.
- **[src/style.css](src/style.css)**, **[src/components/superUserView.ts](src/components/superUserView.ts)**, **[src/utils/requisitionLogic.ts](src/utils/requisitionLogic.ts)**:
  - Hard-set `#ffffff` / `#000000` inside `.printable-slip-box` and `@media print`, and hid `.admin-sidebar`, `.admin-workspace-caption`, and `.su-demo-drawer` in print mode.
  - Swapped small-text semantic colors to higher-contrast tokens (`--su-grn-deep`, `--su-complete-dark`, `--su-mreq-dark`, `--su-areq-dark`).
  - Switched `.su-user-form-grid`, `.su-order-form-grid`, `.su-customer-form-grid`, and `.su-article-form-grid` to `align-items: start` with aligned primary buttons, `.form-hint`, `.su-form-error`, `[aria-invalid="true"]` input/select borders, disclosure chevrons + `:focus-visible` outlines on `<summary>`, `.su-collapsible-body` padding, and `.su-report-sheet-wrap` (`max-width: 920px`).
  - Applied a `12px` readable font-size floor on Super User labels/badges/table headers/controls, `28px` desktop (`44px` coarse pointer) hit targets on `.table-btn` and `.admin-tag-remove`, removed `translateY(-1px)` hover jitter on `.su-chip-btn:hover`, and added `@media (max-width: 900px)` table wrapping and horizontal scroll safety.

### Phase 4 — XSS Hardening, Inline Validation, In-Flight Gating, Focus Restoration & Confirm Dialogs
- **[src/utils/requisitionLogic.ts](src/utils/requisitionLogic.ts)** & **[src/components/superUserView.ts](src/components/superUserView.ts)**:
  - Escaped user/order/database values with `escapeHtml()` and replaced interpolated inline `onclick`/`onchange` handlers in Super User markup with delegated `data-su-action` and `data-su-change` attributes.
- **[src/main.ts](src/main.ts)**:
  - Added Promise-based `openConfirmDialog()` (inside `#global-modal`, Cancel focused first, `Escape` cancels, focus restored on close) and `confirmAndRunAdminAction()` across `adminRemovePendingOrder`, `adminRemoveDropdownItem`, `adminResetSystemUserPassword`, `adminVoidGrnBatch`, `adminVoidReqBatch`, and `adminCloseOrderShort`.
  - Added `runAdminAction()` keyed by `pendingAdminActionKeys` to prevent duplicate concurrent submissions and toggle `disabled` + `aria-busy`.
  - Added field-level validators (`validatePendingOrderInputs`, `validateCustomerMasterInputs`, `validateProductMasterInputs`, `validateSystemUserInputs`, `validatePasswordResetInput`) wired via `applyFieldValidationErrors()` / `clearFieldValidationError()` setting `aria-invalid="true"`, `aria-describedby`, `.su-form-error`, and focusing the first invalid control.
  - Added `buildFocusRestoreSelector()`, `captureRenderFocusTarget()`, `restoreRenderFocusTarget()`, and `captureDirtyFormDrafts()` so keyboard focus and search cursor position survive `renderApp()` re-renders.
